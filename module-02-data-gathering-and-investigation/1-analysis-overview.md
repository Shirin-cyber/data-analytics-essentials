# 1. Analysis Overview

In data analytics, collecting data is only part of the process. Before using it to answer a question, an analyst needs to understand what information is required, what information is available, and whether that information is reliable enough to use.

This module focuses on the early stages of working with data: gathering it, investigating its contents, and identifying whether it needs to be cleaned or prepared.

## The Three Main Questions

During initial data investigation, analysts ask three important questions:

1. **What data do we need?**  
   Identify the information required to answer the business question.

2. **What data do we have?**  
   Examine the available datasets, their contents, and their structure.

3. **Is the data clean?**  
   Check for problems such as missing values, incorrect entries, or other data quality issues.

These questions help analysts decide whether the available data is suitable for the intended analysis and what needs to be done before moving forward.

## The Main Tools Introduced in This Module

### Excel

Excel is a spreadsheet application used to organize, clean, calculate, summarize, analyze, and visualize data. It is especially useful for initial investigation and working with smaller datasets.

### SQL

SQL stands for Structured Query Language. It is used to retrieve and manipulate data stored in relational databases.

### Tableau

Tableau is a data analytics and visualization platform used to explore data and communicate findings through charts, visualizations, and dashboards.

### Kaggle

Kaggle is an online community where people can find datasets, share code, learn from others, and participate in data science projects and competitions.

## Key Takeaway

Before drawing conclusions from data, an analyst must understand what information is needed, what information is available, and whether the data is suitable for analysis. Tools such as Excel, SQL, and Tableau help with different parts of this process.
