# Data Gathering

Before we can analyse anything, we need data to work with. But where does that data come from? It could come from a survey, a company's database, a website, a spreadsheet, or even an application. Finding and collecting the right data is an important part of the data analytics process.

## Where does data come from?

Data analysts can gather data from different sources depending on the question they're trying to answer.

Some common sources include:

- **Surveys and questionnaires:** Collecting responses directly from people.
- **Databases:** Getting information stored in systems, such as customer or sales databases.
- **Spreadsheets and files:** Using existing Excel workbooks, CSV files, and other data files.
- **Websites:** Collecting information that is publicly available online.
- **APIs:** Requesting data from a service or application in a structured way.
- **Sensors and applications:** Gathering information recorded by devices or software.

The important thing is that the source should provide data that is relevant to the question we're trying to answer.

## Web scraping

Sometimes, the information we need is available on a website but isn't provided as a ready-to-use dataset. **Web scraping** is a technique used to extract information from web pages automatically.

For example, someone researching product prices might use web scraping to collect publicly displayed prices from a website.

However, scraping isn't always allowed. Websites may have rules about automated data collection, and privacy, copyright, and access restrictions must be considered before collecting information.

## APIs

An **API (Application Programming Interface)** allows different software systems to communicate with each other. In data analytics, an API can let an analyst request data from an application or online service without manually copying information from its website.

For example, a weather service might provide an API that allows an application to retrieve temperature readings for a particular location.

The data returned by an API may need to be cleaned or transformed before it is ready for analysis.

## Gathering the right data

Collecting a large amount of data doesn't automatically make an analysis useful. We need to ask a few questions first:

- Does the data help answer the question we're investigating?
- Is the source reliable?
- Is the data complete enough for our purpose?
- Are there missing values, errors, or inconsistencies?
- Are we allowed to access and use this data?

These checks help us avoid wasting time analysing data that doesn't actually help answer our question.

## My main takeaway

Data gathering is about finding and collecting the information needed for an analysis. Data can come from many different sources, including files, databases, websites, and APIs. Choosing relevant data from an appropriate source is just as important as analysing it.
