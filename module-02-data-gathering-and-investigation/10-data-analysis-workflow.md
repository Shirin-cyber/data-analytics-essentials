# Data Analysis Workflow

So far, we've looked at where data comes from, how to understand a dataset, and how to choose suitable visualizations. But how do all these things fit together in an actual data analytics project?

That's where the **data analysis workflow** comes in. It gives us a structured way to approach a problem instead of randomly collecting data and hoping to find something useful.

## The main steps

### 1. Ask the right question

Before doing anything else, we need to understand what we're trying to find out.

For example, a college might want to know why student attendance has decreased. This gives the analysis a clear purpose.

Without a specific question, it's easy to collect lots of data that doesn't help us solve the problem.

### 2. Gather the data

Once we know our question, we need to find the information that can help answer it.

For the attendance example, we might collect attendance records, class schedules, and student feedback.

The data should be relevant to our question, and we should consider whether the sources are reliable and whether we're allowed to use the information.

### 3. Investigate and understand the data

Before jumping into calculations, we need to explore what we have collected.

This includes identifying observations, variables, and values, checking for missing information, and looking for errors or inconsistencies.

For example, we might discover that some attendance records are incomplete or that dates have been entered in different formats.

### 4. Clean and prepare the data

Real-world data isn't always neat and ready to use. It may contain duplicates, missing values, inconsistent formats, or incorrect entries.

Cleaning and preparing the data helps make it more suitable for analysis.

For example, we might standardize date formats and investigate duplicate attendance records before continuing.

### 5. Analyse the data

Now we can begin looking for patterns, comparing values, and calculating useful summaries.

A spreadsheet tool such as Excel can help us sort and filter records, calculate averages, count occurrences, and summarize information using PivotTables.

For the attendance example, we might compare attendance rates across different months or courses.

### 6. Visualize and communicate the findings

After analysing the data, we need to present the results in a way that people can understand.

We could use a line chart to show how attendance changes over time or a bar chart to compare attendance across courses.

The goal is to explain what the data tells us and how those findings relate to the original question.

## Does the workflow always happen in a straight line?

Not necessarily!

While these steps provide a useful structure, data analysis is often an iterative process. That means we may need to return to an earlier step when we discover something new.

For example, while investigating attendance records, we might realize that we need additional information to answer our question properly. We may then need to gather more data or revise our analysis.

That's normal. The purpose of the workflow is to guide us, not to force us to follow a rigid sequence when the situation calls for changes.

## My main takeaway

A data analysis workflow helps us move from a question to a meaningful finding in a structured way. We start by understanding the problem, gather relevant data, investigate and prepare it, analyse it, and communicate what we discover.

The most important thing is to keep the original question in mind throughout the process. Collecting and analysing data is useful only when it helps us understand something or make a better-informed decision.
