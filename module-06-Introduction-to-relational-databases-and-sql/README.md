# Module 6: Introduction to Relational Databases and SQL

---

## Why this module matters

We deal with databases all the time, even when we don't notice. Every day, we create and use millions of records of data from all kinds of sources.

**Relational databases** are the most important type of database in data science. So anyone working with data needs to understand how they work, and how to **query** them using **SQL** (Structured Query Language, pronounced "sequel"). That's how you pull out data so it can be analyzed and used.

---

## What you'll learn

By the end of this module, you should be able to:

- Explain the basic concepts of databases and data management
- Write SQL queries to select and output data
