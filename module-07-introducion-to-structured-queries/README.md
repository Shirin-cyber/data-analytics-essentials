# Module 7: Introduction to Structured Queries

---

## Why this module matters

**SQL** (Structured Query Language) is used to query relational databases, where data can be spread across different tables. SQL can **combine data from multiple tables** to return more complex results, and that helps us do analysis.

In this module, we use different types of **joins** to extract and combine data from more than one table.

---

## Module objective

Formulate a structured query to extract and combine data from multiple tables.

---

## What you'll learn

By the end of this module, you should be able to:

- Explain the structure of relational databases
- Create SQL queries that use multiple tables
- Use JOIN and other SQL functions to extract data from multiple tables
- Describe how SQL is used to manage databases
