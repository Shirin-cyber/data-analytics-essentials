# Module 4: Analyzing Data with Excel

Step 4 of the Data Analytics Process is **preparing data for analysis**, and this module is where we actually get our hands dirty doing it in Excel.

---

## Why this module matters

Raw datasets are rarely perfect. They often come with:

- Blank rows or columns
- Data in the wrong format
- Corrupt field entries

Any of these can make your analysis results wrong. So the data has to be **cleaned and transformed** before anything else happens.

In this module we dive deep into Excel. We use it to **import, clean, and prepare data** so it's ready for visualizations.

---

## What you'll learn

By the end of this module, you should be able to:

- Sort and filter data in Excel
- Convert data and apply conditional formatting
- Combine datasets
- Use formulas and functions to do calculations and transform data
- Use pivot tables to summarize, analyze, explore, and present data
