# 5.3 Creating Visualizations with Excel

**Topic objective:** Create visualizations with Excel.

---

## 5.3.1 Steps to create a visualization in Excel

This one's a recap. We already did charts in Excel back in Module 4, so this is the same idea, just now it fits with everything we learned about picking the right chart.

Making a chart in Excel is pretty easy:

1. Enter or select the **data** you want to show
2. Click the **Insert** tab
3. Pick a **chart type** from the list

---

### Example: top 10 movies by budget

Say we want a quick picture of the **top 10 movies by budget**.

**Step 1: Get the data ready**

- **Sort** the budget field in **descending** order (biggest first)
- Select the **top 10 budgets**
- Also select the **10 matching movie titles**

**Step 2: Insert the chart**

- With those cells selected, click the **Insert** tab
- Look at the chart options in the **Charts** toolbar
- Hover over a chart type to see info about it
- Click the **dropdown arrow** next to a chart type to see its subcategories
- Pick a **2-D column chart**

Excel builds the column chart from the selected data and puts it in the workbook. That's our basic chart.

---

## Customizing the chart

A basic chart works, but it's nicer when it's easy to read. Excel gives you lots of ways to customize it.

Click inside the chart area and **buttons show up on the right side**:

| Button | Icon | What it does |
|---|---|---|
| **Chart Elements** | Plus sign (+) | Add or edit things like the title, legend, grid lines, and data labels |
| **Chart Style** | Paintbrush | Set a style and color scheme |

> There's also a third button, **Chart Filters**, which lets you choose which data points show up in the chart.

### Changing the title

Click the chart title text and change it to **"Top 10 Movies by Budget."**

### Adding axis titles

1. Click the chart, then click the **Chart Elements (+)** button
2. Check the box for **Axis Titles**
3. Two text boxes appear on the chart, one for the **vertical** axis and one for the **horizontal** axis
4. Change the vertical axis title to **movie budget**
5. Change the horizontal axis title to **movie title**

This matches what we learned in the last section: always **label your axes**, so people know what they're looking at.

### Resize it

You may also want to **resize the chart** to make it easier to read.

---

## Quick takeaways

- Steps: **select data → Insert tab → choose a chart type**.
- Sort first if you want a ranking, like a top 10.
- Hover over a chart type to learn about it, and use the dropdown arrow to see subcategories.
- A **column chart** works well for comparing one variable across categories.
- **Chart Elements (+)** adds titles, legends, grid lines, and data labels. **Chart Style** (paintbrush) changes the style and colors.
- Always add a **chart title** and **axis titles**.
- Resize the chart so it's readable.
