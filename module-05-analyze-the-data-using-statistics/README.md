# Module 5: Analyze the Data Using Statistics

---

## Why this module matters

Data analytics leans heavily on **statistics**. To analyze and interpret data well, analysts need a solid grasp of the basics.

In this module we build **visualizations in Excel**. But first, we need to understand some statistical concepts, so we can actually make sense of what those visuals are telling us.

---

## What you'll learn

By the end of this module, you should be able to:

- Describe different types of statistics
- Pick the right visualization to explain your analysis results
- Create visualizations with Excel
- Read visualizations to spot anomalies in data
- Use VLOOKUP or XLOOKUP in Excel to find and fix data issues
